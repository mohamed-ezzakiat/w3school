    What is CSS?

    CSS is the languge we use to style a Web page.

  • CSS stands for Cascading style sheets
  • CSS describes how HTML elements are to be displayed on screen, paper, or in other media
  • CSS saves a lot of work. It can control the layout of muliple web pages all at once
  • Exteranal stylesheets are stored in CSS files
